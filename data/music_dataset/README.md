# Song Metadata and YouTube Links Dataset

## Description

This dataset contains metadata and YouTube links for a collection of songs. Each song has two takes, and the dataset includes the following columns:

- **Song Take**: Indicates whether the link is for take 1 or take 2.
- **Song Name**: The name of the song.
- **Ragam**: The ragam of the song.
- **Composer**: The composer of the song.
- **Janya Number**: The janya number of the ragam.
- **YouTube Link**: The URL to the YouTube video.

## Usage

The dataset is provided for academic and research purposes. Please ensure to comply with YouTube's terms of service when accessing the provided links.
